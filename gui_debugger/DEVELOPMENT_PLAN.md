## 7. КОМАНДЫ ЗАПУСКА

### Установка зависимостей

```bash
pip install ttkbootstrap matplotlib Pillow
```

### Запуск GUI (из корневой папки проекта)

```bash
# С RAG-пайплайном (по умолчанию)
python -m gui_debugger.main

# Без RAG-пайплайна (упрощённый режим)
python -m gui_debugger.main --no-rag

# С отладкой
python -m gui_debugger.main --debug
```

### Запуск GUI (из папки gui_debugger)

```bash
cd gui_debugger
python main.py --no-rag
```
