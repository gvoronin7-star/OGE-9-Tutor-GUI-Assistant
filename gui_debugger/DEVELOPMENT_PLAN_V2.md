## 1. ОБЗОР ПРОЕКТА

### 1.1 Назначение

Универсальный GUI интерфейс для OGE Tutor представляет собой **двухрежимное приложение**:

| Режим | Назначение | Целевая аудитория |
|-------|------------|-------------------|
| 👤 **Пользовательский** | Подготовка к ОГЭ, изучение тем, тесты | Ученики 9 класса |
| ⚙️ **Административный** | Отладка, мониторинг, управление | Разработчики, админы |

### 1.2 Отличия от Telegram-бота

| Характеристика | Telegram-бот | GUI приложение |
|----------------|--------------|----------------|
| **Доступ** | Через Telegram API | Локально, без интернета |
| **Интерфейс** | Кнопки в Telegram | Нативное окно Windows/Linux/macOS |
| **Визуализация** | Ограничена | Графики, таблицы, панели |
| **Режим админа** | Нет | Полная диагностика системы |
| **Независимость** | Требует Telegram | Работает автономно |

### 1.3 Связь с документацией

| Документ | Соответствие |
|----------|--------------|
| `docs/USER_GUIDE.md` | Полный функционал бота |
| `docs/API_SPEC.md` | REST API интеграция |
| `docs/ARCHITECTURE.md` | RAG-пайплайн, компоненты |
| `gui_debugger/DEVELOPMENT_PLAN.md` | Предыдущая версия (отладчик) |

### 3.3 Решение тестов

**Файл:** `components/user/test_solver.py`

**Функционал:**
1. Выбор темы (6 кнопок)
2. Выбор сложности (🟢🟡🔴)
