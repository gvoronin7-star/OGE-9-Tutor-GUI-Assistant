# OGE TUTOR GUI v2.0

**Универсальный интерфейс для подготовки к ОГЭ по обществознанию**

---

## 📋 Описание

GUI v2.0 — это **двухрежимное приложение**:

| Режим | Назначение | Аудитория |
|-------|------------|-----------|
| 👤 **Пользовательский** | Подготовка к ОГЭ, изучение тем, тесты | Ученики 9 класса |
| ⚙️ **Административный** | Отладка, мониторинг, управление | Разработчики, админы |

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install ttkbootstrap matplotlib Pillow pandas
```

### 2. Запуск

```bash
# Из корневой папки проекта
python -m gui_debugger.main

# Пользовательский режим напрямую
python -m gui_debugger.main --mode user

# Административный режим напрямую
python -m gui_debugger.main --mode admin

# Без RAG (демо-режим)
python -m gui_debugger.main --no-rag
```

## 👤 Пользовательский режим

### Главное меню

4 основные функции:
- **📚 Изучить тему** — выбор из 6 тем ФИПИ
- **✍️ Решить тест** — генерация тестов с выбором сложности
- **📊 Прогресс** — статистика подготовки
- **❓ Помощь** — справка и советы

### Изучение тем

1. Выберите тему из списка (6 тем ФИПИ)
2. Получите подробное объяснение от RAG-пайплайна
3. Оцените ответ (👍👎🔄)

**Темы:**
- Человек и общество
- Сфера духовной культуры
- Экономика
- Социальная сфера
- Политика
- Право

### Решение тестов

1. Выберите тему
2. Выберите сложность (🟢 Легкий / 🟡 Средний / 🔴 Сложный)
3. Ответьте на 5 вопросов
4. Получите результат с оценкой

**Система оценивания:**
- 80-100% → 5 (Отлично) 🎉
- 50-79% → 4 (Хорошо) 💪
- 0-49% → 3 (Повторить) 📚

### Прогресс

- Тем изучено: X / 6
- Тестов пройдено: X
- Точность: X%
- Оценка: 5-балльная

## ⚙️ Административный режим

### 9 вкладок мониторинга:

| Вкладка | Описание | Статус |
|---------|----------|--------|
| 📱 **Chat** | Отладка чата без Telegram | ✅ |
| 🔍 **RAG** | Визуализация поиска чанков | ✅ |
| 📊 **Metrics** | Метрики RAG-пайплайна | ✅ |
| 📚 **Database** | Просмотр 204 чанков ФИПИ | ✅ |
| 📝 **Logs** | Просмотр логов запросов | ✅ NEW |
| 💾 **Cache** | Управление кэшем Redis | ✅ NEW |
| 🤖 **LLM** | Мониторинг GigaChat | ✅ NEW |
| ⚙️ **Config** | Настройки системы | ✅ NEW |
| 👥 **Users** | Управление пользователями | ✅ NEW |

### Функции администратора

- **Просмотр логов**: фильтрация, экспорт, очистка
- **Управление кэшем**: просмотр ключей, статистика, очистка
- **Мониторинг LLM**: статус, лимиты, ошибки
- **Конфигурация**: настройки RAG, LLM, кэша
- **Пользователи**: список, статистика, блокировка

## 🔧 Конфигурация

### Сохранение настроек

Настройки сохраняются в `gui_debugger/config.json`:

```json
{
  "rag": {
    "top_k": 5,
    "threshold": 0.5
  },
  "llm": {
    "model": "GigaChat-Max",
    "timeout": 30
  },
  "cache": {
    "ttl_top": 24,
    "ttl_normal": 6
  }
}
```

### Переменные окружения

См. `.env` в корневой папке проекта.
