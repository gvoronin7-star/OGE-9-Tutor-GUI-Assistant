## 🎯 КАК РАБОТАЕТ СИСТЕМА СЛОЖНОСТИ

### Архитектура:

```
ПОЛЬЗОВАТЕЛЬ ВЫБИРАЕТ ТЕМУ → LLM ГЕНЕРИРУЕТ ВОПРОСЫ → ВОПРОСЫ СОХРАНЯЮТСЯ → ОТОБРАЖЕНИЕ
                              (с difficulty="medium")    (difficulty в JSON)    (🟡 MEDIUM)
```

### Уровни сложности:

| Уровень | Эмодзи | Описание | Пример |
|---------|--------|----------|--------|
| Easy | 🟢 | Простые вопросы на знание фактов | "Что такое экономика?" |
| Medium | 🟡 | Вопросы на понимание и применение | "Какая система основана на частной собственности?" |
| Hard | 🔴 | Вопросы на анализ и оценку | "Как ЦБ использует ставки для борьбы с инфляцией?" |

## 🔄 ФИЛЬТРАЦИЯ И СОРТИРОВКА

### Фильтрация по сложности:

```python
# Получить только лёгкие вопросы
easy_questions = [q for q in all_questions if q.get("difficulty") == "easy"]

# Получить только сложные вопросы
hard_questions = [q for q in all_questions if q.get("difficulty") == "hard"]
```

### Сортировка от лёгких к сложным:

```python
difficulty_order = {"easy": 1, "medium": 2, "hard": 3}
sorted_questions = sorted(all_questions, key=lambda x: difficulty_order.get(x.get("difficulty"), 0))
```

### Смешанный тест (все уровни):

```python
# 40% easy, 40% medium, 20% hard
mixed_test = easy_questions[:2] + medium_questions[:2] + hard_questions[:1]

## 🔍 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Промпт для LLM:

```python
prompt = f"""На основе следующего материала составь {num_questions} вопросов для ОГЭ по обществознанию на тему "{topic}".

Уровень сложности: {difficulty}
- easy: простые вопросы на знание фактов (определения, названия)
- medium: вопросы на понимание и применение (классификации, сравнения)
- hard: вопросы на анализ и оценку (причинно-следственные связи, прогнозы)

Формат ответа (JSON):
{{
    "questions": [
        {{
            "question": "Текст вопроса",
            "answers": ["А", "Б", "В", "Г"],
            "correct_answer": 0,
            "explanation": "Пояснение",
            "difficulty": "{difficulty}"
        }}
    ]
}}"""
```

### Структура вопроса:

```python
question = {
    "question": str,          # Текст вопроса
    "answers": List[str],     # 4 варианта
    "correct_answer": int,    # Индекс правильного (0-3)
    "explanation": str,       # Пояснение
    "difficulty": str         # "easy" | "medium" | "hard"
}
```
