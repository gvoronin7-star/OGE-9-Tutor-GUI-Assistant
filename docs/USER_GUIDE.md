# Руководство пользователя OGE Tutor GUI

## Введение

OGE Tutor GUI — это десктопное приложение для подготовки к ОГЭ по обществознанию с RAG-пайплайном. Приложение помогает изучать темы, решать тесты и отслеживать прогресс в подготовке к экзамену.

## Начало работы

### Запуск приложения

1. Убедитесь, что Python 3.11+ установлен
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python -m gui_debugger.main --mode user
   ```

### Главное меню

После запуска приложения вы увидите главное меню с кнопками:

- 📚 **Изучить тему** — получить подробную информацию по теме
- ✍️ **Решить тест** — пройти тест по выбранной теме
- 📊 **Прогресс** — посмотреть статистику обучения
- ❓ **Помощь** — получить справку

## Функции приложения

### Изучение тем

1. Нажмите **📚 Изучить тему**
2. Выберите тему из списка
3. Получите подробное объяснение с примерами
4. Следите за прогрессом изучения

**Доступные темы:**
- Человек и общество
- Сфера духовной культуры
- Экономика
- Социальная сфера
- Политика
- Право

### Решение тестов

1. Нажмите **✍️ Решить тест**
2. Выберите тему
3. Нажмите **"▶️ Начать тест"**
4. Или выберите **"🎲 Тест по всем темам"** для комплексного тестирования
5. Отвечайте на вопросы, выбирая вариант из 4 предложенных
6. Получайте мгновенную проверку с пояснениями

**Особенности тестов:**
- Автоматическое смешивание сложности вопросов
- Таймер времени на тест
- Подсветка правильных/неправильных ответов
- Автопереход к следующему вопросу
- Индикация доступного количества вопросов

### Отслеживание прогресса

Нажмите **📊 Прогресс** для просмотра:
- Количество изученных тем
- Число пройденных тестов
- Процент правильных ответов
- Общая статистика
- История занятий

### Получение помощи

Нажмите **❓ Помощь** для получения:
- Списка функций
- Описания интерфейса
- Советов по использованию

## Часто задаваемые вопросы

### Как работает приложение?

Приложение использует RAG-пайплайн для поиска релевантной информации в базе знаний и генерации ответов с помощью LLM (GPT-4o-mini).

### Сохраняется ли мой прогресс?

Да, прогресс сохраняется в локальной базе данных и доступен при следующем запуске приложения.

### Можно ли пересдать тест?

Да, вы можете проходить тесты по одной теме несколько раз.

### Что делать, если приложение не отвечает?

Попробуйте:
1. Проверить подключение к интернету (для LLM)
2. Перезапустить приложение
3. Проверить логи в папке `logs/`

### Как проверить работу без LLM?

Приложение автоматически использует кэш или демо-вопросы, если LLM недоступен.

## Система оценивания

Тесты оцениваются по следующим критериям:

| Результат | Оценка |
|-----------|--------|
| 80-100% | Отлично! 🎉 |
| 50-79% | Хорошо, но есть над чем работать 💪 |
| 0-49% | Советую повторить тему 📚 |

## Административный режим

Для разработчиков и отладки доступен административный режим:

```bash
python -m gui_debugger.main --mode admin
```

**Возможности административного режима:**
- Просмотр логов в реальном времени
- Мониторинг метрик RAG-пайплайна
- Тестирование поиска чанков
- Управление кэшем
- Просмотр статистики системы

## Советы по подготовке к ОГЭ

1. **Регулярность** — занимайтесь каждый день по 15-20 минут
2. **Понимание** — не просто запоминайте, а понимайте материал
3. **Практика** — решайте как можно больше тестов
4. **Ошибки** — анализируйте свои ошибки и работайте над ними
5. **Повторение** — периодически возвращайтесь к пройденным темам
6. **Комплексность** — используйте тесты по всем темам для полной подготовки

## Техническая поддержка

При возникновении технических проблем:
1. Проверьте логи в папке `logs/`
2. Убедитесь, что все зависимости установлены
3. Проверьте файл `.env` на наличие необходимых переменных
