# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased] - 2026-08-31 — 2026-09-04

> Версия не присвоена намеренно — это решение владельца, не техническое.
> Период охватывает 46 коммитов: полный аудит-цикл десктопного
> приложения и запуск целого нового мобильного трека. Подробности
> каждого пункта — `decisions/decision-log.md` и `ONBOARDING_ROADMAP.md`.

### Добавлено

- **Мобильное приложение (Flutter/Android)** — новая платформа,
  `mobile/` внутри этого репозитория, все 5 фаз концепт-плана
  реализованы:
  - Автономный режим — темы, тесты, прогресс полностью на устройстве,
    без сервера и интернета
  - Серверный режим — тот же FastAPI-бэкенд, что у десктопа
    (`api/mobile_routes.py`, новые эндпоинты)
  - Офлайн-семантический поиск по 157 чанкам базы ФИПИ (ONNX
    rubert-tiny2, инференс на устройстве)
  - Иконка, сплэш-экран с названием, релизная сборка
    (`--split-per-abi`, 57.7 МБ)
  - UX/UI-аудит всех 10 экранов, все 11 находок закрыты (статус
    «изучено» в списке тем, разбор ответов теста, доступность
    цветовой индикации, тёмная тема и другое)
- Банк вопросов расширен с 30 до 98 (5 → 16-17 на тему, 6 типов
  вопросов вместо прежних 5) — общий источник для десктопа и мобильного

### Изменено

- Реальная база ФИПИ перечанкована и переэмбеддена с исправленным
  пайплайном Squeezer (`pdfplumber` вместо `pypdf`, починено
  определение заголовков) — 204 → 157 чанков, мусорные фрагменты убраны
- `mypy` стал блокирующим шагом CI (долг по типизации закрыт с 155 до 0
  ранее, снят `|| true`)

### Исправлено

- 17 багов, найденных полным аудитом 2026-08-31: GUI подвисал на каждом
  LLM-запросе, вкладка «Кэш» в админке всегда падала, hash-ключи
  кэша/статистики сбрасывались при каждом перезапуске, фолбэк
  Redis→InMemoryCache не срабатывал, и другие (подробности —
  `decisions/2026-08-31_audit-diff.md`)
- Демо-ответ на любой вопрос по теме был дословно одинаковым независимо
  от вопроса
- 3 из 6 официальных тем ФИПИ в демо-контенте молча подменялись темой
  «человек и общество»
- Мобильный поиск падал в релизной сборке (R8 обрезал классы ONNX
  Runtime без keep-правил ProGuard) — недостижимо в debug-сборке, не
  замечено раньше
- Дефолтный адрес сервера в мобильных настройках (`10.0.2.2:8000`)
  резолвился только внутри Android-эмулятора, не на реальном телефоне
- CI (`Lint`) был красным на двух последних пушах подряд — `black` не
  прогнан по двум новым скриптам, что молча останавливало workflow
  перед шагом `mypy`

## [2.3] - 2026-04-11

### Добавлено

- **Управление RAG базой через GUI**
  - Панель управления в административном режиме
  - Выбор папки с новой базой данных
  - Валидация структуры базы (chunks/, metadata/, indices/)
  - Автоматическое резервное копирование перед заменой
  - Мониторинг статуса и статистики в реальном времени
  
- **Исправления UX**
  - Улучшены кнопки выбора режима (весь фон кликабелен)
  - Добавлена цветовая подсветка режимов
  - Исправлено отображение прогресса (теперь обновляется при изучении тем и прохождении тестов)
  - Добавлена индикация загрузки тестов

### Изменено

- Увеличено время отображения объяснений с 2 до 5 секунд
- Обновлено реальное количество вопросов по темам
- Удалены неработающие кнопки "Далее" и "Пропустить"

### Исправлено

- Прогресс теперь корректно обновляется при завершении тем и тестов
- Счётчик вопросов показывает точные значения для каждой темы
- Заголовок "Выберите тему" обновлён (убрано упоминание сложности)

## [2.2] - 2026-04-10

### Изменено

- **Убран выбор сложности** — вопросы теперь смешиваются всех уровней (как на реальном ОГЭ)
- Интерфейс упрощён — убраны радио-кнопки выбора сложности

### Добавлено

- **Индикация количества вопросов** — показывается точное число вопросов по теме
- **Тест по всем темам** — комплексное тестирование со случайной выборкой вопросов
- **LLM прогресс** — индикатор генерации теста в реальном времени

### Удалено

- Выбор сложности (easy/medium/hard) из интерфейса тестирования
- Кнопки "Далее" и "Пропустить" (заменены на автопереход)

## [2.1] - 2026-04-10

### Добавлено

- **Индикатор прогресса при ожидании LLM**
  - Прогресс-бар с анимацией
  - Текст с названием модели (gpt-4o-mini)
  
- **Предзагрузка тестов**
  - Фоновая загрузка популярных тем
  - Кэширование предзагруженных тестов
  - Мгновенный старт для часто используемых тем
  
- **Таймер (секундомер) для тестов**
  - Отсчёт времени с точностью до 0.1 сек
  - Отображение в формате "M:SS"
  - Статистика времени в результатах
  
- **Подсветка ответов**
  - Зелёная подсветка правильного ответа
  - Красная подсветка неправильного ответа
  - Показ правильного ответа при ошибке
  - Объяснение после каждого ответа
  
- **Автопереход к следующему вопросу**
  - Автоматический переход через 2 секунды
  - Кнопка "Пропустить" для быстрого перехода
  
- **Индикация количества тестов**
  - Счётчик доступных тестов по теме
  - Обновление при смене темы/сложности
  - Индикация загруженных тестов

### Изменено

- Улучшены кастомные стили для кнопок (success, danger, pale variants)
- Добавлено логирование событий тестирования

## [2.0] - 2026-03-25

### Добавлено

- Полная миграция с Telegram-бота на десктопное GUI-приложение
- Интеграция Tkinter + ttkbootstrap для GUI
- RAG-пайплайн с Faiss и Whoosh
- Поддержка GPT-4o-mini через ProxyAPI
- Система кэширования (Redis / In-memory)
- Генератор тестов с поддержкой разных уровней сложности

### Изменено

- Архитектура: Bot → GUI-first приложение
- LLM: GigaChat → GPT-4o-mini
- Основной интерфейс: Telegram → десктопное окно

### Удалено

- Весь код Telegram-бота (aiogram)
- Зависимости, связанные с Telegram
- Устаревшая документация по боту
